# Publicatiechecklist

Technische versie 1 ≠ navigatieklare liveversie. Vink af vóór publieke “gecontroleerde” claim.

## Geografie

- [ ] Exacte Avans-binnentuin / ingang / verzamelpunt bevestigd
- [ ] Stoppositie Westerpark bevestigd
- [ ] Stoppositie Willemspoort bevestigd
- [ ] Voetgangersroute avans → westerpark → willemspoort → avans gelopen/gecontroleerd
- [ ] Toegang binnentuin en eventuele beperkingen bekend
- [ ] `coordinates` en `geometry` ingevuld; `mapMode` → `geographic` indien van toepassing
- [ ] Conceptbanner verwijderd of aangepast na controle

## Metadata

- [ ] Afstand opnieuw gemeten voor gekozen route → `verifiedDistanceMeters`
- [ ] Looptijd gecontroleerd → `verifiedWalkingMinutes`
- [ ] Eventuele volledige route-URL → `verifiedRouteUrl`
- [ ] `sourceIndication` niet meer als publieke waarheid gebruikt

## Links en assets

- [ ] Heijmans-link nog bereikbaar en passend als CTA
- [ ] Overige externe links gevalideerd
- [ ] Foto-/logo-rechten vastgelegd
- [ ] Kaartattributie compleet als OSM of andere brondata wordt gebruikt

## Hosting en WordPress

- [ ] HTTPS-hosting van `dist/`
- [ ] Parent- en child-origins geconfigureerd
- [ ] Iframe + hoogtescript op echte WP-pagina getest
- [ ] CSP / frame-ancestors / X-Frame-Options gecontroleerd
- [ ] Fallback-locatielijst op de pagina geplaatst
- [ ] Inhoud en plaatsing goedgekeurd door GBC en CFTF
